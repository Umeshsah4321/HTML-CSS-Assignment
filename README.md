## Project Description

This project is a basic HTML and CSS webpage containing a navigation bar, a hero section, course cards, a practice-project section and a footer. The project demonstrates HTML structure and fundamental CSS styling techniques learned during the module.

## Technologies Used

- HTML5
- CSS3

## Project Features

- Navigation bar with six links
- Hover effect on navigation links and buttons
- Single card component design
- Four consistent course cards
- Images with CSS styling
- Margins, padding and borders
- Typography and text properties
- Footer section
- No JavaScript, Flexbox or CSS Grid

## Challenges and Solutions

**Challenge 1:** The spacing between navigation links was inconsistent.

**Solution:** I reviewed margin and padding and adjusted the spacing of the navigation links using CSS.

**Challenge 2:** The images needed to fit consistently inside the cards.

**Solution:** I used fixed image width and height values and applied border radius to keep the card design consistent.
